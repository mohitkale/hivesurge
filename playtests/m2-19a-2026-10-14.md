# M2-19a: phone and tablet emulation perf (?debug), main e7abf40

Tester: hivesurge-qa. Box Chromium, NO GPU (software WebGL / SwiftShader). Level clover-run. 300+ unit samples taken with ?stress=320, because organic play could not reliably reach 300.

| Profile                                | Median fps at 300+ | Peak draw calls | Peak units | Input lag                               |
| -------------------------------------- | ------------------ | --------------- | ---------- | --------------------------------------- |
| Desktop 1280                           | 4                  | 69              | 755        | FAIL (about 130-200 ms at about 10 fps) |
| Phone 393x852 (DevTools device mode)   | 12                 | 69              | 320        | FAIL (taps take seconds)                |
| Tablet 820x1180 (DevTools device mode) | 3                  | 68              | 749        | FAIL (PLAY tap took about 8 s)          |

- Draw calls: PASS (66-69 at any swarm size, against a target of 100 or fewer).
- FPS against the 50 fps target (M2-19a / M3-2a): NOT VALID on this box. The renderer is CPU-only, so these numbers describe the box, not a device. They are far below the 44 fps software figure measured before the art pass, which is a possible perf regression worth an eng profile.
- Input lag: not separable from software-render frame time, so INCONCLUSIVE for real devices. Move to M2-19b (real device, Mohit).
- Starter Pack (PR 051 re-check): +500 coins, +50 gems and no-ads PASS. Skin FAIL: save.ts adds 'starter' to owned skins, but src/art/skins.ts defines no 'starter' skin and there is no skins UI to show it.
- G4 re-check: NOT RUN (too slow to reach battle 6+ at these frame rates).

Verdict: draw-call budget PASS. FPS and lag need a GPU or a real device. Starter skin still FAIL.
